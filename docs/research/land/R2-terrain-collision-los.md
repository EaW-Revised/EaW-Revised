# Land research R2: terrain collision and line of sight

## Scope and evidence

Read-only debug-build research, 2026-10-22, extends U-LC-2 of the
[land combat walk](../../behaviour/walks/land-combat.md). This note separates
projectile terrain contact, movement passability, firing feasibility and fog
reveal. The existing [projectile walk](../../behaviour/walks/projectiles.md),
[land pathing walk](../../behaviour/walks/land-pathing.md) and
[land environment walk](../../behaviour/walks/land-environment.md) remain the
owners of their shared rules. No retail or GPU capture was run, and no simulation
implementation is changed here.

Evidence IDs LR2-E01 onward identify successful read-only debug-build inspections.
Their private source map and raw results remain in ignored research output. XML
corroborates authored inputs; it does not establish a runtime consumer or an
absent tag's default. All numeric tolerances below are code values unless marked
as authored examples. The planned consumers are L1 terrain field, L2 unit tables,
L3 land start, L4 pathfinding, L5 local movement and L6 presentation. Tracking:
ground-combat architecture (legacy EAWR-3776), land targeting/fog (legacy EAWR-1454), and
land movement (legacy EAWR-1451).

## Architecture handoff

U-LC-2 is resolved here for the inspected shared projectile paths and normal
fog-reveal chain. It remains open for the explicitly listed special paths,
geometric boundary cases and live retail acceptance. No universal heightfield
body sweep for every movable object is established by the projectile query.

L1 needs separate height/surface sampling, cell admission and finite segment
contact interfaces. Segment contact carries a hit fraction, world contact point,
normal and surface-event metadata. Keep projectile-category admission outside
that geometric query so another caller cannot accidentally inherit a shot's
terrain bypass. Land rocket construction also samples terrain height; its
retained path is separate from checking each flight step for contact.
Use bilinear interpolation for the checked height sampler and the observed cell
diagonal for geometric contact; an endpoint-only height check cannot establish
the same contract. Include water-plane contact policy as an explicit simulation
input rather than reading viewer state during a simulation query. The remaining
water-setting qualification is listed below.

L2 must preserve authored category, grenade/sticky and bomb-fall inputs. L3 and
land fog retain the normal circular reveal contract. L4/L5 keep movement masks,
footprints, occupancy and local terrain response. L6 receives the selected
contact and authored effect inputs, including the separate surface-event offset;
the current presentation terrain mesh is not a simulation service.

These are integration decisions from the rule rows, not a new retail frame
schedule. Use immutable terrain and copied projectile/target inputs for
partitioned contact work, then ordered commits under the existing projectile
contract. R1 owns land phase placement and same-frame dependencies. No shared
tag-registry status changes are made by this documentation task.
