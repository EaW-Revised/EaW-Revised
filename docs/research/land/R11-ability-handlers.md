# R11: land ability handler internals

This walk extends the open questions U-LAB-1 through U-LAB-9 in
[land abilities](../../behaviour/walks/land-abilities.md). It records handler-local
activation, effect lifetime, targeting and cleanup contracts for the land ability
programme. It changes no runtime code and claims no new retail capture.

Evidence is read-only inspection of the **debug build**, plus selected declarations
in the effective XML. Opaque R11-E identifiers resolve to private evidence in
ignored `out/research/gc-land-r11/`; binary locations and engine identifiers stay
there. R11-D01 identifies the selected XML snapshot. Authored values are examples,
not universal defaults or limits for mods. A static branch is distinguished from
an observed retail outcome throughout.

Integration labels follow the ground-combat plan: L1 is terrain, L2 unit data and
companies, L4/L5 pathfinding and local movement, L6 presentation, and P5 land
abilities. G1 through G9 are the existing land-ability walk's integration groups.
Global service placement, cadence and same-frame ordering remain R1's decisions;
local timer arithmetic below does not establish those schedules. The
[frame schedule](../../behaviour/frame-service-schedule.md) and
[hero handler framework](../../behaviour/walks/heroes.md) retain their own scope.
The [land frame map](R1-frame-map.md), especially LR1-04 and its periodic-behavior
ledger, supplies the containing scheduling contract. It does not yet settle the
specialized confusion cleanup deadline or mine invocation phase.
