# Land research R12: weather, campaign victory and persistence

Read-only research, 2026-10-22. This extends the [land environment walk](../../behaviour/walks/land-environment.md),
[land combat walk](../../behaviour/walks/land-combat.md), [GC tactical walk](../../behaviour/walks/gc-tactical.md)
and [campaign return rules](../../behaviour/walks/gc-movement-control.md). It supplies implementation decisions
for the ground-combat programme (legacy EAWR-3776); it changes no gameplay.

Evidence is the **debug build**, effective XML data and the explicitly cited earlier rules. No retail executable
capture, rig run or build was performed. New opaque evidence IDs identify private reads in ignored
`out/research/gc-land-r12/`; that directory also holds the evidence index. Earlier rules retain their earlier
evidence, rather than becoming new independent observations here. Static findings describe the inspected
debug build; they do not establish release-executable equivalence or a complete restored runtime.
