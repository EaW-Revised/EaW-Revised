# Land transport drop-in

This read-only debug-build walk qualifies the transport-arrival part of
[land combat](../../behaviour/walks/land-combat.md) U-LC-5 / LC-51 and
[reinforcements](../../behaviour/walks/reinforcements.md) U-11. It decides the
arrival state needed by land reinforcement integration (legacy EAWR-1457), in the
ground-combat programme (legacy EAWR-3776). It adds no implementation or retail
capture. Static closure below does not close the runtime qualification rows.

Existing contracts remain authoritative: LC-42..50 and WR-79..84 own land
placement, capacity, human/AI exemptions and AI point selection; WGT-78..82 in
[campaign handoff](../../behaviour/walks/gc-tactical.md) own fresh scene entry.
Fresh initial forces and mid-battle reinforcement arrivals are different paths.
The [frame-service schedule](../../behaviour/frame-service-schedule.md) and the
land frame-map walk own global order, cadence and same-frame ties. This note
describes transitions inside the arrival handler, without establishing a new
global service order.

Sources are the **debug build**, effective XML data and the cited rule notes.
Opaque evidence IDs identify private read-only inspections. Binary names,
addresses and raw output remain in ignored `out/research/gc-land-r5/`.
Code constants are labelled; authored values are examples, not mod limits.
No tag-registry application status changes in this documentation-only walk.

## Timeline and implementation boundary

For a successful ordinary arrival, the sourced progression is:

**admission/reservation → hidden waiting → descent → unload hold → group
deployment(s), each followed by a hold → completion/control release → takeoff
→ proxy removal**.

For a constant unmodified deployment clock and `g` successful groups, the
handler schedules `g + 1` two-second waits between landing-threshold completion
and finalization. Animation duration, waiting obstruction and service admission
are additional. This describes the timer-reset structure, not an exact measured
native-frame duration. A modifier change can affect successive waits differently.
No successful group becomes freely selectable just because it has appeared.

Land reinforcement integration (legacy EAWR-1457) can now design the incoming
reservation, member/group cursor, rollout state, timer and completion protocol.
L1 supplies terrain height; L2 supplies companies, teams and unique carriers;
L4/L5 supply layout and rollout; L6 supplies the animation/fog/audio view. L3's
setup path needs its own acceptance case. The campaign provider carries persistent
transport identity and the native continuation state. None of this authorizes
using a space arrival timer or inventing an observed stock animation duration.
