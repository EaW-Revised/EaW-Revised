## Ordered service contract

The containing order is commands, scoring, land prefix, shared mode work, players,
global gameplay scripts and story, then mode-clock advance. Within shared mode,
the order is fog decay, tracking, accounting rollover, synchronized objects and
their manager tail, presentation objects and their manager tail, timeline,
collision service, movement coordinator, setup, retreat, victory countdown,
bombing, bombardment, income, multiplayer balancing and pending domination,
followed by end handling. Presence and editor/setup gates still apply.

This is a dependency map, not a proposal to copy a serial object loop. L1..L6
retain immutable inputs, partitioned preparation and ordered commits, with equal
results on 1/2/4/8 workers. A land adapter is still missing at the comparison
base: the existing domain seam deliberately refuses land session creation until
the terrain field exists. The table therefore says **missing**, rather than
claiming a measured land regression.
