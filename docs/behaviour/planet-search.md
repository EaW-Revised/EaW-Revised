# Galactic planet search (project addition, DEV-25)

The owner requested this addition in the planet-search feature request (legacy EAWR-6936).
It has no original-game equivalent. The reference establishes interaction and row
content; artwork and fonts come from the existing dialog kit.

| Rule | Project behaviour |
|---|---|
| PS-01 | `Data/XML/RevisedPlanetSearch.xml` supplies the dialog geometry and its named controls. Higher valid layers replace lower ones. An invalid layer retains the last valid definition with one EAWR-UI diagnostic. There is no engine layout fallback. The normal GUIDialogs skin, fonts and named overrides apply. The dialog anchors at the right edge using its scaled XML offset. The shipped layout is 264 by 280 reference units: the owner-requested ten-percent width increase expands the header, list and search field, keeps the eight-unit side insets and right-aligned Close button, and leaves text height and picture proportions unchanged. |
| PS-02 | Campaign planets with a nonblank display name enter the index, including undiscovered planets. Scene-only decoration and deliberately blank-name mod dummies never enter it. An undiscovered row keeps its grey disabled styling and shows its name with the map's hidden-planet picture, using the same model and shell material. It has no extra hidden-planet text, faction emblem, tooltip or selection highlight. Clicking positions the camera at its system without selecting it; Enter and navigation skip it. Once discovered, it becomes a normal row. Every click revalidates the planet and world-input admission against the current publication. |
| PS-03 | Names are the same localized display names the map HUD has loaded, including its internal-name fallback. Unicode lowercase substring matching is incremental. Empty text shows every named campaign planet. Alphabetical order uses the user locale's collation of lowercase display names; equal names preserve campaign order. A discovery/name change replaces the index. |
| PS-04 | A row contains the available planet picture, the name, then the last-known owner's faction emblem, using the observer's apparent owner rather than the campaign's true owner. A mounted faction `Icon_Name` is preferred; otherwise the command bar's authored `Text_Allegiance_A` emblem table and loaded side names supply the same symbol as the HUD. Unknown ownership has no emblem. A mod can hide either art column. Icons are squares with the list font's measured line height; no icon pixel size is authored in code. The layout's optional `Row_Scale` (default 1.0) scales the kit's List_Box font size for the result rows, and both icons follow the text height. The emblem keeps a gap of a quarter of the row height before the list's right edge, and the list clips row text, pictures and emblems to its rectangle. The native list scrolls and only visible rows have emblem controls. Closed search performs no indexing or texture work. |
| PS-05 | Ctrl+F opens search in the galactic map. Bare F retains its existing context: the original default profile maps F/D to next/previous-unit commands, which navigate planets in GC (WGUI-146). The general keyboard editor remains read-only (ST-K1). A tour, modal, loading screen, tutorial lock or tactical battle refuses the open. Search works while paused. The finder is a panel rather than a full-screen modal: outside its rectangle, pointer input reaches the game while it stays open, and keys reach the game unless the finder holds explicit keyboard focus. Native pointer events update focus before GUI dispatch, so even the next key in the same frame reaches the correct target. Leaving its rectangle releases its controls' keyboard focus; re-entering restores search focus. Clicking the field or Ctrl+F also focuses it, even with the pointer outside; that focus lasts until the pointer next enters and leaves the panel. Ctrl+F while already open preserves the filter. Inside it, text focus consumes world keys; Up/Down choose a selectable row, Enter or a left click picks, Escape or the Close button (`TEXT_BUTTON_CLOSE` from the text table) closes. Rows show no hover tooltip; the row already shows the name. |
| PS-06 | A pick keeps the dialog open (filter, selection, scroll position and text focus stay) and uses ordinary planet selection with the same camera-position effect as Page Up/Down. It submits no simulation order and adds no save/checkpoint or replay state. |

The approved scope excludes an exact-match toggle and home-capital action.

The initial picture path uses an existing 2D `Icon_Name` from the loaded planet
type, when present. Stock planets commonly provide a model without a 2D icon;
those rows show a neutral disc scaled to the text. The optional
`PlanetSearchThumbnails` provider is owned by the galactic presentation state and
is queried only for onscreen rows. It may return a live texture; the row retains
that texture directly. A null result keeps the placeholder. The galactic state supplies that provider from the first open (PS-08).
No substitute model or fixed planet list is used.

| Rule | Project behaviour |
|---|---|
| PS-08 | A row without a mod 2D icon shows its planet's own map model (including a destroyed-state model), using the close-up surface alternate and its live idle animation. Hidden planets retain the hidden-shell alternate. WGUI-05 supplies the map's alternate semantics; selecting close-up for this project-added finder is the owner's presentation rule. The model uses its own idle clip and material clock on the galaxy animation clock. A pause holds it as it holds the map. A model without an idle clip stays still. The picture uses the galaxy's lighting and the planet's map orientation, viewed along the map camera direction taken when the box opens. A flat disc therefore keeps its map tilt. The picture draws what the map draws at the planet's place: every galaxy object within 0.5 map units of the planet's map position (for example a mod's sector spiral or logo placed on a system) is drawn with its own map scale, orientation, offset, idle clip and material rules. Framing comes from the union of those objects' placed bind-pose bounds: its largest half-extent fills the cell, so a round body, a flat disc or a spiral with small planets inside fits exactly and keeps the map's proportions. A lone turning model is framed about its pivot (when its bounds do not hold the pivot, on its farthest corner from the pivot, so its idle swing stays in the cell); otherwise the union's centre is used. The pictured system uses alternate 1 as a close-up camera target; co-located decorations retain their ordinary map alternate. An undiscovered campaign planet with a grid shell keeps alternate 2, and the row redraws when it is discovered. Framing uses the selected alternate's surfaces, rather than an overview bounding box. Independent animated bones, including asteroids, retain their authored relative motion. Every row has the same visual size, and no name or model is special-cased. The background is transparent with no frame. An additive glow outside the body keeps its hue at an alpha equal to its brightness. Onscreen rows share one offscreen atlas of 16 cells, sized to the row's text height in device pixels at 2x supersampling. A row beyond the cells keeps the placeholder. Model decode and texture loading run off the main thread, at most four models at once, and at most one model uploads per frame. At most 32 models stay resident; least-recently-shown models are evicted, never one a row shows. A model that fails to decode, frame or upload shows the placeholder for the session and is reported once in the viewer report (`planet_search_pictures.failures`). A frame in which no row asks for a picture renders nothing: both viewports stay disabled and the pre-draw hook disconnects. |
| PS-09 | Galaxy surfaces authored with `Nebula.fx` use the shared environment-effect planner, including its authored texture bindings, additive material and existing galaxy animation clock. The galaxy upload, read-ahead and row pictures share this route; no planet or model name selects it. Original Remake 4.0 galaxy-map captures show nebula art around Hapes and Utegetu. |

The optional galaxy zoom-timing probe also records the first and latest actual renderer bone palettes for visible finder rows and their corresponding map objects in `planet_search_pictures.spin_samples`. It uses the shared animation clock; the normal viewer collects no palette samples.
