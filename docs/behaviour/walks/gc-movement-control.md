# Galactic movement and control walk

FoC galactic conquest, researched 2026-10-02. This covers campaign and multiplayer GC time, fleet membership, planet paths and travel, orbital/surface presence, political control, conflict admission, tactical handoff and return. It records the interfaces to economy, production, AI, story/Lua, tactical combat and autoresolve; those subsystems own their internal calculations. It does not implement the galactic layer.

The original walk records GC gaps at its research baseline; tactical analogues do not count as a GC implementation. Rules are supported by debug-build readings, with stock-data values where stated, except the explicitly unverified wreck/damage rule. WGM-113 adds a bounded original-game capture observation. The [gap matrix](#gap-matrix) names the future integration points and M3 tickets; the [unverified list](#unverified-and-capture-plan) remains part of the implementation contract.

The mode manager services scoring, the active mode, voting, voting progress, then pending-battle work. Within galactic mode the observed order is planet visibility, shared mode service, optional cinematics, fiscal processing, then periodic victory/planet-destruction presentation. Fleet locomotion and planet control run through their object's behavior services. The tables preserve order **inside each inspected entry point** and the causal command/departure/arrival/battle/return sequence. WGM-89 now establishes outer command/object/conflict/fiscal phase order. Individual object/behavior tie order remains WGM-U01; the maintenance-delay question is now narrowed by GFC-22/27 and GFSC-19 in the frame schedule; do not promote phase order into a universal entity order.

Fleet membership service and galactic locomotion each return a base service interval of **1 logical frame** (code). The fiscal duration uses the synchronizer's seconds-to-frames conversion, whereas hero creation records their own rounded galactic-frame deadline. Political transition uses elapsed service frames divided by logical FPS. These clocks are distinct from wall-clock battle-vote timeout and from the calendar text on the HUD.
