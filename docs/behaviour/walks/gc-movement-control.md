# Galactic movement and control walk

FoC galactic conquest, researched 2026-10-02. This covers campaign and multiplayer GC time, fleet membership, planet paths and travel, orbital/surface presence, political control, conflict admission, tactical handoff and return. It records the interfaces to economy, production, AI, story/Lua, tactical combat and autoresolve; those subsystems own their internal calculations. It does not implement the galactic layer.

Every rule below is **missing** in the remake's GC layer. Tactical analogues do not count as a GC implementation. There are 88 rules: 87 supported by debug-build readings, with stock-data values where stated, and one explicitly unverified wreck/damage rule. The [gap matrix](#gap-matrix) names the future integration points and M3 tickets. No retail capture was performed for this walk; the [unverified list](#unverified-and-capture-plan) is part of the implementation contract.

## Evidence and update boundaries

Evidence IDs EGM-01 through EGM-36 and EGM-38 refer to debug-build readings; EGM-37 denotes winning retail XML. The private address/source map and raw outputs remain in ignored research storage. A parser-table hit proves a tag is parsed, not that an inspected rule consumes it. Values below are authored stock values, not proposed engine literals. WGM-83..88 were added in the command-path pass; their stable IDs are placed beside the earlier rules they refine.

The mode manager services scoring, the active mode, voting, voting progress, then pending-battle work. Within galactic mode the observed order is planet visibility, shared mode service, optional cinematics, fiscal processing, then periodic victory/planet-destruction presentation. Fleet locomotion and planet control run through their object's behavior services. The tables preserve order **inside each inspected entry point** and the causal command/departure/arrival/battle/return sequence. The exact global ordering of object services, conflict queues and fiscal processing on a coincident frame is unverified (WGM-U01); the table order must not be promoted to a universal total frame order.

Fleet membership service and galactic locomotion each return a base service interval of **1 logical frame** (code). The fiscal duration uses the synchronizer's seconds-to-frames conversion, whereas hero creation records their own rounded galactic-frame deadline. Political transition uses elapsed service frames divided by logical FPS. These clocks are distinct from wall-clock battle-vote timeout and from the calendar text on the HUD.
