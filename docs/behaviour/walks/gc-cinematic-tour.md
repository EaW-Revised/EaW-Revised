# Galactic cinematic tour (the camera button and the battle-camera key on the galaxy map)

Research for (legacy EAWR-6291). Sources: a read-only debug-build walk (evidence IDs map to a private address ledger) and one rig
capture of the original (galactic conquest, 1280 by 720, default profile: Space showed the tour, a second Space about 33 s later
still toured from a different view, a mouse click ended it). Values are engine coordinates and seconds of game time. The space
and land battle camera is a different walk ([battlecam](battlecam.md): BCAM-01..04 give the shared key, the mouse ending and
the bands). **Unverified** marks a gap, not a retail rule; those parts are decompile-only or choices of the remake.

| ID | Rule | Evidence |
|---|---|---|
| GCT-01 | The galaxy map's authored camera button and the battle-camera key (the default binding is Space, BCAM-01) start the same "movie mode"; on the galaxy map its first choice is the galactic tour. The button takes no tutorial gate. The key acts on its **release** and only when the tutorial's combat-cinematic permission is on and the tutorial is not locked. It does nothing in a battle or while loading (a battle has its own camera, BCAM-02), and the debug build's start refuses while a battle is being resolved (a conflict state on the object manager; that it is the pending battle prompt is **unverified**). The remake also refuses while any galaxy modal is open (the one set `GalaxyModals`: the retreat, save, score and battle windows, the story and reference windows, the hero, market, weapon and corruption menus and an action menu) and while the game is paused (and ends a tour a pause or a modal interrupts), because the bands hide the GUI and with it the pause banner and its Resume Game button (**unverified**: the original's paused look under the cinematic GUI is not known). | debug build; rig capture (Space) |
| GCT-02 | Pressing the key again while a tour plays does not end it: it starts a fresh tour (a new shuffle, the clock back to zero). The button is on the hidden GUI then, so the mouse is what ends a tour (GCT-08). | debug build; rig capture |
| GCT-03 | The tour visits the map's planets in a shuffled order. If a planet is selected it is swapped to the front of the shuffled list. The first entry of the list is only used for the bounds of the whole set and is **not** visited, so with a selection the tour begins with a planet after it (**unverified**: decompile only; the capture did not select a planet first). With fewer than two planets there is nothing to visit (**unverified**: the original would loop on an empty tour). | debug build |
| GCT-04 | Each visited planet takes three camera keys at seven-second steps (seven times the logical frame rate in frames each), 21 s per planet; the target keys sit at the first and the third of them. | debug build |
| GCT-05 | The keys: the **far** key puts the eye at the length of the half extents of the union of all planet boxes away from the planet, on a line 15 to 30 degrees above the galaxy plane (the elevation a random whole number of degrees; the azimuth the ring angle plus 15 degrees); the **close** key puts it on a horizontal ring at five lengths of the planet model's half extents, at a random ring angle; the third key is the far key mirrored through the planet (below the plane). The side flips from one planet to the next. The target is the planet's centre throughout, and moves to the next planet over the seven seconds between slots. The remake takes a planet's extent from the skeleton radius times its scale (the real model bounds are not read yet). | debug build (geometry); remake choice (extents) |
| GCT-06 | When the tour's clock ends and movie mode is still on, a new tour starts, so the tour goes on until the player ends it. Holding Tab at that moment holds the last scene instead of starting the next (**not implemented**). The clock counts logical frames (the remake counts game seconds and does not scale them to fast forward: **unverified**); in the remake a pause ends the tour (GCT-01). | debug build |
| GCT-07 | Starting the tour slides the two letterbox bands in over half a second, each the authored `Camera_FX_Manager_Letterbox_Height` of the screen height (HCB-11c; the same bands a story script's `Letter_Box_In` draws), and disables the game GUI (command bar, radar and the rest). The planets' name labels stay on screen (capture). The pointer is hidden in the original's battle camera (BCAM-04); whether it is on the galaxy map is **unverified** and the remake leaves it. The game is not paused: the day counter and credits keep running (capture). | debug build; rig capture |
| GCT-08 | Any mouse event ends the tour except a pointer move smaller than a twentieth of the screen width and height (measured from the previous event): a press of any button, the wheel and a larger move. The ending event is consumed (a click that ends the tour selects nothing). Ending slides the bands out over half a second and brings the GUI back. Escape ends it in the tactical camera (BCAM-04); on the galaxy map the walk found no handler (**unverified**), and the remake does not end the tour on Escape. | debug build; rig capture (click) |
| GCT-09 | While the tour plays its pose is the map's camera; the player's own camera (selection, zoom state, pan) is untouched and is what the map returns to. Pan keys, edge scrolling and the camera keys (Home, Page Up, Page Down) do nothing meanwhile. | project |
| GCT-10 | The tour is presentation only: nothing is saved, hashed or replayed, and a new or loaded session starts with no tour. | project |
| GCT-11 | **Space.** The original's Space (the battle-camera key) starts the tour on the galaxy map and does not pause: the debug build has no key that pauses the galaxy clock (the command bar's key handler only tracks Shift; the pause control is the clock panel's button and the story rewards). The remake bound Space to pause before this rule; the opt-in **Options > Tweaks > Space pauses the galactic game** (default off, DEV-13, `gameplay.space_pauses_galactic`) gives Space to the pause again: on, Space only pauses (on its press, as the clock panel's button would) and never starts the tour, and the tour stays on the camera button; off, Space starts the tour on its release and does not pause. The pause button and the paused banner with its Resume Game work in both settings. | debug build; remake choice (opt-in deviation) |
| GCT-12 | **Unverified, decompile only:** the speed profile between keys (the remake eases with a trapezoid profile: the shares of a segment the keys' ease values name), the keys' distances (the remake's planet extents, GCT-05), the ring angle and elevation draws, the selected planet being skipped (GCT-03), the permission flag (GCT-01: the story reward that turns it off is not wired), the other movie-mode shots the original tries after the tour (a hero clash, a bombing run, an interesting object: those need a battle). | debug build |
