# Galactic conquest: UI, sensors, map input and camera

This FoC walk covers discovered planets, observer intelligence, orbit and transit
fleet visibility, spies/probes, the galactic HUD, map selection/input, camera,
advisor messages and event history. It records the debug build and effective
stock XML inspected on 2026-10-02. WGUI-108 adds a bounded retail observation
captured on 2026-10-09; other rows retain their stated source boundaries. Evidence IDs
EGU-01..12 resolve to private research retained outside the committed tree.

The initial implementation census and Phase 3 packet table below describe the
2026-10-02 baseline. Planet observer state and fleet filtering have since landed;
the implementation-readiness continuation at the end updates those boundaries.
XML names below are the mod-facing names.

## Scope and evaluation boundaries

Objects are planets and their orbit/ground containers, travelling fleets,
per-player intelligence modifiers and ability sources; presentation observes
them through the HUD and camera. The galactic service refreshes discovery before
ordinary mode service. Fiscal update and pause semantics belong to
[the movement walk](gc-movement-control.md), WGM-01..06, and
[the economy walk](gc-economy-production.md), WGEP-01..04. Input executes on events;
camera flights advance with wall-clock time. Observer mask refresh, GUI system
update, GUI component service and rendering are distinct entry points. Rules are
ordered within each verified entry point; U-01 does not establish their total
order across the engine's frame loop.

The hero/corruption walk owns action eligibility, ability invocation, costs,
despawn/death/respawn and corruption changes. This walk owns the intelligence
effect received from those actions and its presentation. Travel orders and
tactical handoff stop at WGM-07..38 and WGM-39..82. AI context stops at
[the AI walk](gc-ai.md), WGA-06..08, WGA-18 and WGA-55. Checkpoint contents belong
to the session/save walk; this walk names the state its consumers need.

## Frame schedule clarification

The [galactic frame schedule](../galactic-frame-service-schedule.md) narrows
U-01 through GFS-03/05/10..15 and GFC-21: mode-entry discovery precedes current
object movement; scheduled creation/conflict/deletion precede fiscal, and
player/global/story consumers precede mode-timer advance. GFD-23/GFSC-13 keep
delayed discovery distinct from synchronous arrival visibility. This sources
the simulation boundary in WGUI-93; GFS-21/22 and GFC-28..30 now source the earlier outer UI/advisor boundary,
later hint production, counter initialization and repeated topology expansion.
Observer-effect listeners, runtime cascade/list ties and physical render/input
gates retain U-01/U-03 and GFSC-20..22/25 qualification.

Open-row follow-up: [GFS-21/22/GFC-28..30/GFD-29/30](../galactic-frame-service-schedule.md)
narrows WGUI-01..05/67/71/79/93/104 and U-01/U-06. A qualifying already
discovered planet still expands discovery at each mode-entry pass; discovery
alone does not qualify another planet to propagate it. The earlier outer HUD
update cannot consume a hint queued at the later player turn. Hint deadlines
read the currently selected mode; advisor fades use outer elapsed milliseconds.
GFSC-20..22/25 retains runtime invocation, callback/list, display and restore
qualification, with fog on for intelligence observations.
