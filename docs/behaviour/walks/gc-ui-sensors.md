# Galactic conquest: UI, sensors, map input and camera

This FoC walk covers discovered planets, observer intelligence, orbit and transit
fleet visibility, spies/probes, the galactic HUD, map selection/input, camera,
advisor messages and event history. It records the debug build and effective
stock XML inspected on 2026-10-02. No retail observation is claimed. Evidence IDs
EGU-01..12 resolve to private research retained outside the committed tree.

**Ours is missing for every rule.** Existing tactical implementations provide
integration points, not a galactic implementation. The gap table maps every rule
to a module and a Phase 3 packet. XML names below are the mod-facing names.

## Scope and evaluation boundaries

Objects are planets and their orbit/ground containers, travelling fleets,
per-player intelligence modifiers and ability sources; presentation observes
them through the HUD and camera. The galactic service refreshes discovery before
ordinary mode service. Fiscal update and pause semantics belong to
[the movement walk](gc-movement-control.md), WGM-01..06, and
[the economy walk](gc-economy-production.md), WGEP-01..04. Input executes on events;
camera flights advance with wall-clock time. Observer mask refresh, GUI system
update, GUI component service and rendering are distinct entry points. Rules are
ordered within each verified entry point; U-01 does not establish their total
order across the engine's frame loop.

The hero/corruption walk owns action eligibility, ability invocation, costs,
despawn/death/respawn and corruption changes. This walk owns the intelligence
effect received from those actions and its presentation. Travel orders and
tactical handoff stop at WGM-07..38 and WGM-39..82. AI context stops at
[the AI walk](gc-ai.md), WGA-06..08, WGA-18 and WGA-55. Checkpoint contents belong
to the session/save walk; this walk names the state its consumers need.
