# Shader translation reporting

These are project reporting rules. They do not describe original-game internals.

- **STR-01:** The activation owner supplies metadata projections over its owned results, after activation completes. `build()` borrows these views only for its call. It never owns compilation, selects source versus compiled form, loads packages, publishes a renderer generation or changes admission. The owner retains every full diagnostic independently of report caps and delivers at most one note per completed generation. Cancelled/stale generations are not published by this helper.
- **STR-02:** Routes are `translated`, `hand_adapter_approximation`, `surface_omitted`, and `missing_effect_green`. Causes do not select routes. Only a truly absent selected effect can use the green route. Opt-out, unavailable packages and unsupported shaders are distinct causes. A translated effect with harmless compiler or cache warnings produces Details without a fallback note. An observed nontranslated route produces one concise note with a Details action when bounded Details are available. Malformed-policy Details identify `shader_translation`; when accompanied by a nontranslated route the note also names that field.
- **STR-03:** Group by canonical effect identity, validated source SHA-256 and reason. Unknown/invalid hashes cannot merge separate selected-effect records. Each retained context preserves failure phase, warning/error severity, route, selected form, layer, mount, logical source, adapter, selected technique, technique/pass/shader stage/entry/profile and location. Equal retained contexts count occurrences. Processing, groups, contexts per group, identifier sizes and output bytes each have injected limits. Overlong identities are omitted rather than truncated into false equality. Counters saturate. Omitted rows are counted as rows, never claimed unique groups. Any processing or retention omission marks counts partial; route/row counts cover the processed subset exactly, while duplicate counts cover comparisons against retained contexts only. Unseen effects' diagnostic counts are unknown. Output includes retention omissions when space permits, and exposes truncation separately.
- **STR-04:** Input framing uses `stage_input`; descriptor scans use `descriptor_scan`; reflection uses `reflection`. Actual compiler, backend, reflection, link, state and semantic failures keep their typed causes. The reporter does not parse compiler strings. Missing package roots, closed/default-disabled runtimes requested for translation, unsupported platforms and native load failures mean `package_load/dependency_unavailable`. Verified pinned-member/path/guard/hash/size/identity failures mean `dependency_integrity`; export/version/ABI/foreign-module refusals mean `dependency_abi`. Explicit policy opt-out alone means `selection/opted_out`; malformed policy blocks translation with `selection/malformed_policy` (see [STO-01](../design/shader-translation-opt-out.md)). TODO: P2b must supply typed `load_failure` before native load failures can be projected as `dependency_unavailable`. Do not reinterpret `missing_export` or parse its message; missing exports remain `dependency_abi`.
- **STR-05:** Invalid cached schema/encoding/identity/hash/references/counts/stages mean `cache_read/cache_failure`, a recoverable miss; storage failure means cache-read/write failure. Neither changes route or implies a bad package/missing effect. Invalid fresh backend output means failure at its validating phase, such as `reflection/backend_failure`. Budget/cancellation keeps its actual phase and typed reason. Source preprocessing, effect parsing and stage compilation retain their actual operation. Actual Godot program linking belongs to admission and uses `godot_admission/link_failure`.
- **STR-06:** Location coordinates explicitly distinguish source line/column, original compiled-effect byte ranges and compiled-stage byte ranges. Unknown is absent, never line zero. Conflicting representations, zero source coordinates and overflowing byte ranges report unknown. The producer may add a stage's effect-relative offset only with a real mapping. Generated stage-byte offsets are not logical source offsets, so `compiled_stage` never prints a location-source name even if supplied. Source mappings and parsed source locations may be projected when known. The helper performs no coordinate conversion.
- **STR-07:** Ordinary Details contain bounded identifiers and typed metadata, with control/non-ASCII bytes escaped. The API has no raw diagnostic message, source body, generated text or attachment field. Viewing Details and opting out give no export consent; any later generated-text attachment requires separate explicit consent for that attachment. Full owned records remain with the activation owner, not in this bounded report.

The CPU tests use invented identifiers and typed causes. They cover grouping across phases, severities, provenance and routes; location spaces; cache warnings; partial counts; retention/output caps; and the single-note contract. Wiring policy before FX/FXO cache/admission and presenting the report once per activation remain the admission owner's integration work.
