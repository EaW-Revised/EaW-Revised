## Interface

A **service frame** is an admitted logical frame, not a render frame, wall-clock
second, fiscal cycle, replay command tick or child-battle tick. Let **t** denote
the galactic mode frame read at service entry. The ordinary unpaused frame
advances that timer at its tail. A paused mode can retain t while outer services
continue; a retained galaxy under a tactical child has no galactic mode service.
The synchronizer's service argument and the mode timer must stay distinct.

Inputs are due synchronized commands, active-mode and pause state, due service
deadlines, live presence/ownership, queue records, accounts and script state.
Outputs are movement/control/production commits, fiscal payments and window
advance, notifications, queued conflicts and script actions. Some notifications
are synchronous; the later story pump is not the sole delivery boundary.

Object services read live state at their positions in the service list. There
is no original global movement/control/production sweep. The remake retains
immutable partition inputs and ordered commits; preserve the observable read
boundary, without adding a serial per-entity loop to reproduce the original list.
