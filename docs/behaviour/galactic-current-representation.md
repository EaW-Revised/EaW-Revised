# Galactic current actor representation

Strategic original type, current actor type and creation source are independent
saved facts. The current reader refuses an absent identity or a zero current type
with `current_representation_unavailable`; it never substitutes the original.

| Rule | Observable contract | Evidence |
| --- | --- | --- |
| CRP-01 | A company creates its authored transport and retains its company original. A squadron creates an outer fleet and a separate current squadron container retaining the represented squadron template; contained craft retain their constructed types. Parent changes alone do not change current type. | debug build; WGM-133/134; WGA-312 |
| CRP-02 | Generic squad and team generation copies source actor usability under WGA-315. Such qualified generated births carry their actual source, delivered before the child. Production squadron assembly instead creates ordinary children; containment alone does not prove flag inheritance. | debug build; WGA-315/316; production assembly observation |
| CRP-03 | A literal type change updates the current type reference without rewriting the strategic original. No inferred transport, team or squadron transition is supplied for an unqualified type. | debug build; targeted type-change observation |
| CRP-04 | Current/source records are written at construction, type, parent, ownership and loss commits. Native private creation exposes both records and its sparse ordered birth frontier before world publication. A prepared private pool commit suppresses only that shadow's duplicate birth delivery. Load publication emits no ordinary birth. | project producer contract; WGA-300..316 |

The galaxy checkpoint section version and production input codec are bumped for
the new census row fields and validated current squadron binding. Older project
formats are unsupported. Current records participate in the canonical census
hash; copied snapshots retain their immutable records. Idle ticks reuse the
publication and make no representation scan or actor-change allocation.

The current type owner must supply a validated literal for unsupported team
formation, boarding or tactical-only conversions; this producer does not invent
those world transitions. Tactical return preserves the existing current identity
while the actual return writers update parent/location and retire lost actors.
