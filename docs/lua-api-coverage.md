Generated by `python -m tools.lua_api_scan`. Each cell is `call sites / scripts blocked`. Ground-battle-only calls are parked and not listed. The full table with call-site detail is the scan's JSON output.
**Static versus runtime.** The scan executes no Lua and runs no game. Which scripts belong to which host, which functions a host binds, and when a call runs (load, start, recurring) are inferred from file paths, XML, the C++ registration sites and a call graph, so a row is a candidate gap, not an observed failure. The only runtime facts are the lines of the 'Runtime cross-check' table, which come from a live game log triage (2026-11-19) and are not generated by the scan. Limits: `tools/lua_api_scan/README.md`, section Limits.
